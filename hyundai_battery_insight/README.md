# Hyundai Battery Insight

Hyundai Battery Insight is a Home Assistant App for correlating 12V battery level, HV Battery Level, odometer movement and available Hyundai / Kia Connect vehicle data without directly requesting a vehicle refresh.

The app was developed against a **Hyundai Tucson PHEV, model year 2025**.

For installation, configuration and interpretation details, see [DOCS.md](DOCS.md).

The current UI is **Dutch only**.

This is an independent community project and is not affiliated with or endorsed by Hyundai, Kia, Home Assistant, or the Hyundai / Kia Connect project.
